## Descripción del Proyecto

Este repositorio contiene la implementación y el análisis comparativo del rendimiento de diversos **algoritmos de ordenamiento**. El proyecto está estructurado para evaluar el impacto real de la complejidad temporal y espacial mediante dos enfoques:
1. **Versión Ineficiente:** Implementaciones básicas o ingenuas (enfoque de fuerza bruta o alta redundancia computacional).
2. **Versión Optimizada:** Implementaciones eficientes que aplican mejores prácticas algorítmicas y optimizaciones de código.

Para llevar a cabo la medición, el proyecto expone estos algoritmos a través de una API REST desarrollada con **Spring Boot**, permitiendo simular cargas concurrentes y realizar pruebas de rendimiento (*benchmarking*) utilizando **Apache JMeter**.

## ⚙️ Tecnologías Utilizadas

* **Java** (JDK 17+)
* **Spring Boot** (Construcción de la API REST)
* **Apache JMeter** (Pruebas de carga y análisis de rendimiento)
* **Maven / Gradle** (Gestión de dependencias)
* **Git & GitHub** (Control de versiones)
